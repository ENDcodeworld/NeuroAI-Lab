## 🎯 研究方向

| 方向 | 描述 | 状态 |
|:-----|:-----|:-----:|
| 📡 信号采集 | EEG/EMG/EOG 信号采集与预处理 | 🚧 |
| 🧹 信号处理 | 滤波、去噪、特征提取 | 🚧 |
| 🧠 解码算法 | 运动意图解码、情绪识别 | 🚧 |
| 🤖 机器人控制 | 脑控机器人系统 | 📋 |
| 🎮 应用开发 | 脑控游戏、辅助设备 | 📋 |

## 📐 技术架构

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  信号采集层  │ →  │  信号处理层  │ →  │  解码识别层  │ →  │  应用控制层  │
│ EEG/EMG     │    │ 滤波/去噪   │    │ ML/DL模型   │    │ 机器人/游戏  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 🚀 快速开始

```bash
git clone https://github.com/ENDcodeworld/NeuroAI-Lab.git
cd NeuroAI-Lab
pip install -r requirements.txt
```
